Library Management System SQL

Project Overview

The Library Management System is a SQL-based project designed to manage books, publishers, library branches, borrowers, and book loans efficiently.

Features

- Manage book and publisher details.
- Maintain library branch information.
- Store borrower details.
- Track book loans and book copies.
- Use SQL queries and stored procedures to retrieve library information.
- Generate reports about borrowed books and library branches.

Technologies Used

- Microsoft SQL Server
- SQL (Structured Query Language)
- Tables, Relationships, Queries, and Stored Procedures

Project Objective

The objective of this project is to understand database management concepts and implement a library database using SQL.

Project Type

SQL Internship Project
